# Algorithms

## Preprocessing
Sequences are normalized to uppercase. Basic DNA character validation is performed. Invalid characters raise exceptions. Sequences maintain their original coordinate system.

## KMP
The Knuth-Morris-Pratt algorithm avoids unnecessary comparisons by precomputing an LPS array.
### Complexity
Preprocessing: O(m), Searching: O(n), Overall: O(n + m), Space: O(m)

## Rabin-Karp
Rabin-Karp utilizes a rolling hash.
### Collision Verification
Because different strings can yield the same hash (hash collision), explicit character-by-character comparison is performed whenever hashes match.
### Complexity
Expected/Average: O(n + m), Worst-case: O(nm), Space: O(1)

## Anchor Generation
Anchors are generated by finding exact matches of length `>= L_min`. 

## Anchor Merging & Conflict Resolution
Overlapping or adjacent candidate anchors that share the same offset are merged. 
Conflicts are resolved by length descending, and then start positions.

## Gap Extraction
For a set of ordered non-overlapping anchors, Prefix, Internal, and Suffix gaps are extracted. 
If 0 anchors exist, a single gap across the whole sequences is generated.

## Gap Features & Classification
Each gap evaluates:
- `length_difference = abs(ref_len - query_len)`
- `mismatch_ratio = length_difference / max(ref_len, query_len)`
Based on `gap_length_threshold` and `gap_mismatch_threshold`, gaps are classified as `short_length_matched` or `long_or_length_mismatched`.

## Strategy Selection
- `short_length_matched` -> `Banded DP`
- `long_or_length_mismatched` -> `Full DP`

## Full DP
Global sequence alignment (Needleman-Wunsch).
### Complexity
Time: O(rq), Space: O(rq)

## Banded DP
Global alignment restricted to a diagonal band `|i - j| <= band_width`.
Boundary Warning: If the traceback path touches the edges of the valid band, `boundary_touched` is flagged to True.
### Complexity
Time: O(g_len * band_width), Space: O(g_len * band_width)
